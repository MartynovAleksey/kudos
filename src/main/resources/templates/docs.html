API reference

The REST API is described by an OpenAPI document and an interactive Swagger UI:

  • Swagger UI — try each endpoint
  • OpenAPI JSON — the raw spec

Every /api/** call runs as the signed-in user's own Kerberos identity. Authenticate with HTTP Basic (LDAP credentials) or the browser session from the login form. Authorization is applied by each service (HDFS, Ozone, HBase, Kyuubi).

Configuration

Settings live in an external file mounted at /etc/k8spark-ui/application.yml (loaded via spring.config.additional-location) and can be edited without a rebuild — restart the app service to apply.

Logging

Application logs are written to standard output and to a rolling file under logs/. Adjust levels with logging.level.<package> and the file location with logging.file.name. User actions are recorded to a separate audit log and, when configured, published to Kafka.
