API reference

The REST API is described by an OpenAPI document and an interactive Swagger UI:

  • Swagger UI — try each endpoint
  • OpenAPI JSON — the raw spec

Every /api/** call runs as the signed-in user's own Kerberos identity. Authenticate with HTTP Basic (LDAP credentials) or the browser session from the login form. Authorization is applied by each service (HDFS, Ozone, HBase, Kyuubi).

Components

Each component below is one of the areas you see in the interface.

Editor

Runs SQL against the cluster's query engines. Pick an engine from the tabs at the top; write SQL in the editor (Ace, with autocomplete on Ctrl + Space) and run it with Execute (the statement at the cursor) or Execute all. Results are shown as a table and can be exported to Excel. Output is split into Result, Log (live engine logs, session engines only) and Session History tabs.

  • Kyuubi Spark SQL — Spark SQL through Kyuubi. Supports named sessions: start one with +, tune engine parameters, restart or close it. Query mode runs each statement in its own short-lived connection instead of a persistent session.
  • Kyuubi Flink SQL — Flink SQL through Kyuubi, with the same session model; the running job's dashboard opens from Jobs.
  • Trino — interactive Trino queries using the signed-in user's Kerberos identity (delegation). No sessions; errors and past runs appear under History.
  • StarRocks — StarRocks queries over the MySQL protocol via a service account. No sessions; History records past runs.

Files

Browses HDFS over WebHDFS: navigate directories, preview files, upload, and manage permissions — all as your own Kerberos identity.

Ozone

Browses the Ozone object store through its ofs:// filesystem, the same way as the file browser.

HBase

A full table browser over the HBase REST Gateway: create, alter and drop tables and column families; scan with filters and pagination; edit rows and cells; and bulk-upload data.

Jobs

Lists cluster applications on two tabs, each with its own filters:

  • Spark — applications from the Spark History Server; open one to see its UI embedded in the KUDOS chrome (reverse-proxied).
  • Flink — running and completed Flink applications; open one to see its dashboard embedded, with Flink's own side panel hidden. Administrator-only.

Documentation

This page: the API reference, a description of every component, and the configuration and logging reference.

Interface settings

Opens from the sidebar. Sets the theme (light / dark / follow the system), collapses the sidebar to an icon rail, and — for administrators — controls which left-panel tools and which SQL engines are visible to everyone. Theme and sidebar are per-browser; tool and engine visibility are deployment-wide and take effect on each user's next sign-in.

Configuration

Settings live in an external file mounted at /etc/kudos/application.yml (loaded via spring.config.additional-location) and can be edited without a rebuild — restart the app service to apply.

Logging

Application logs are written to standard output and to a rolling file under logs/. Adjust levels with logging.level.<package> and the file location with logging.file.name. User actions are recorded to a separate audit log and, when configured, published to Kafka.
